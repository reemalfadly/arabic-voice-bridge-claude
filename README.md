# 🎙️ الجسر الصوتي — كلّم كلود بالعربية صوتياً

> **Arabic voice bridge for Claude.** Send an Arabic voice note to a Telegram bot →
> it's transcribed locally on your machine → a full‑permission Claude agent runs the
> command on your PC and sends the result back.

**المشكلة:** تطبيقات كلود لا تقبل الرسائل الصوتية بالعربية — بالإنجليزية فقط — فيبقى
المستخدم العربي مضطراً للكتابة.

**الحل:** جسر يفرّغ صوتك العربي **محلياً على جهازك** (بدون رفعه لأي مكان)، فيستلمه كلود
نصاً وينفّذ أوامرك على الجهاز، ويرجّع لك الرد والملفات في نفس محادثة تلغرام.

**فكرة وبناء وإعداد · م. ريم الفضلي**

```
📱 رسالة صوتية بالعربية  →  تلغرام  →  bridge.py  →  تفريغ محلي  →  🤖 كلود ينفّذ  →  الرد + الملفات
```

## المتطلبات

- ويندوز

- [Claude Code](https://docs.claude.com/claude-code) + اشتراك Claude فعّال
- حساب تلغرام
- ~2 جيجا مساحة فارغة (لمرة واحدة، لتنزيل نموذج التفريغ الصوتي)

## تحميل الملفات


## التشغيل — 5 خطوات

**1. ثبّت الأدوات**

- Python من [python.org](https://www.python.org/downloads/) — فعّل خيار «Add python.exe to PATH».
- uv — في PowerShell:
  ```powershell
  powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
  ```
- Claude Code — من الموقع الرسمي لـ Anthropic.

**2. سجّل دخول كلود واحصل على توكن**

```bash
claude setup-token
```

يفتح المتصفح ← وافق ← انسخ السطر الذي يبدأ بـ `sk-ant-oat01-`.

**3. أنشئ بوت تلغرام**

في تلغرام كلّم `@BotFather` ← أرسل `/newbot` ← اختر اسماً ومعرّفاً ينتهي بـ `bot` ←
انسخ **توكن البوت** (`8123...:AA...`) ← افتح محادثة البوت واضغط **Start**.

**4. اعرف رقم محادثتك (chat id)**

أرسل أي رسالة لبوتك، ثم افتح في المتصفح (ضع توكن بوتك مكان `<TOKEN>`):

```
https://api.telegram.org/bot<TOKEN>/getUpdates
```

خذ الرقم الذي يلي `"chat":{"id":`.

**5. جهّز وشغّل**

- انقر **`اعداد.bat`** نقرتين ← الصق: توكن البوت، chat id، توكن كلود ← يكتب `run-bridge.bat` تلقائياً.
- انقر **`run-bridge.bat`** نقرتين ← أول تشغيل ينزّل المكتبات ونموذج الصوت (~دقيقتين).
- عند وصول رسالة **«🤖 السكرتير شغّال»** في تلغرام — أرسل رسالة صوتية بالعربية وجرّب:
  > «سوّ لي ملف نصّي فيه: حليب، خبز، بيض — وأرسله لي»

> **بديل يدوي:** بدل `اعداد.bat`، افتح `run-bridge.bat` بمحرّر نصوص (كليك يمين ← Edit)
> وعبّئ المفاتيح الثلاثة بين علامتَي الاقتباس.

**الدليل الكامل المصوّر:** افتح [`voice-bridge-guide.html`](voice-bridge-guide.html) في المتصفح.

## تشغيل تلقائي مع ويندوز (اختياري)

`Win`+`R` ← اكتب `shell:startup` ← Enter. كليك يمين على `run-bridge.bat` ←
«إنشاء اختصار» ← قص الاختصار والصقه في مجلّد «بدء التشغيل».

## ⚠️ الأمان

الوكيل يعمل بوضع `bypassPermissions` — ينفّذ أوامر على جهازك **بدون تأكيد**.

- البوت يرد على **`chat id` واحد فقط** (المضبوط في الإعداد). لا تعطّل هذا القيد.
- **لا تشارك توكن البوت.** إن تسرّب: `Revoke` فوراً من `@BotFather` وأنشئ توكناً جديداً.
- من يصل إلى محادثة تلغرامك يصل إلى جهازك. فعّل التحقق بخطوتين.
- شغّله على جهازك الشخصي فقط.
